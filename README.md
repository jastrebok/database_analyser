# database_analyser

Initial project layout for a Node.js-based database analyser.

## Project structure

- `src/index.js` - package entry point and minimal runnable bootstrap
- `src/core/databaseAnalyser.js` - core analyser class
- `src/reporters/summaryReporter.js` - summary formatting helper
- `test/databaseAnalyser.test.js` - basic Node.js tests for the starter layout

## Available scripts

- `npm start` - runs the starter flow against a small example schema
- `npm test` - runs the Node.js built-in test suite
